# KiCad 10 Shortcuts (Ubuntu) : UNified

> **Tip:** To view or customize hotkeys in KiCad, navigate to **Preferences → Preferences… → Hotkeys**.

| Context | Shortcut | Action |
| :--- | :--- | :--- |
| General | `Ctrl + S` | Save the current project or sheet |
| General | `Ctrl + Z` | Undo the last action |
| General | `Ctrl + F1` | View the full list of active hotkeys in the current editor |
| General | `Esc` | Cancel the active tool or command and return to the normal pointer |
| Ubuntu OS | `Alt + Print Screen` | Capture the active window |
| Ubuntu OS | `Ctrl + Alt + T` | Open a terminal |
| Navigation | `Home` | Zoom to fit (displays the entire schematic sheet or PCB) |
| Navigation | `F4` | Center the view on the current cursor position |
| Navigation | `F5` | Refresh / redraw the screen |
| Navigation | `Ctrl + Arrows` | Pan |
| Navigation | `Ctrl + Shit +` | Zoom in |
| Navigation | `Ctrl + -` | Zoom out |
| Schematic | `A` | Add a symbol |
| Schematic | `W` | Route a wire |
| Schematic | `C` | Copy the item under the cursor |
| Schematic | `V` | Edit component value |
| Schematic | `Q` | Place a "no connection" flag |
| Schematic | `T` | Add text |
| Schematic | `Ctrl + L` | Add Label |
| PCB Editor | `D` | Drag an item or connected track/pad |
| PCB Editor | `U` | Toggle between measurement units (e.g., millimeters and mils) |
| Canvas | `Space` | Reset relative coordinates (`dx`, `dy`, `dist`) to zero at the cursor |
| Canvas | `M` | Move the selected item or item under the cursor |
| Canvas | `R` | Rotate a selected symbol or footprint |
| Canvas | `X` / `Y` | Mirror along the X or Y axis |
| Canvas | `E` | Edit properties of the item under the cursor |
