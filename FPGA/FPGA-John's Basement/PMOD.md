# What is PMOD?

PMOD stands for Peripheral Module, an open standard created by 
[Digilent](https://digilent.com/reference/pmod/start) for connecting 
small input/output extension boards to microcontrollers and FPGA development boards. 
[1, 2] 

## Overview and Design

* Definition: A standardized add-on hardware module used to add new features—like sensors, displays, or motor controllers—to a main processing board.

* Connection Types: Uses compact 6-pin or 12-pin physical header connections with a standard 0.1-inch (2.54mm) pitch.
* Protocols: Supports standard communication protocols including SPI, I²C, UART, and general-purpose input/output (GPIO).
* Power: Typically supplies 3.3V logic to operate safely with modern low-voltage embedded systems. [1, 2, 3, 4, 5, 6] 

## Common Uses

* Sensors: Measuring temperature, light, and 9-axis motion (accelerometers/gyroscopes).
* Input/Output: Adding buttons, switches, LEDs, and multi-touch displays.
* Communication: Enabling Wi-Fi, Bluetooth, or Ethernet capabilities. [3, 7]
