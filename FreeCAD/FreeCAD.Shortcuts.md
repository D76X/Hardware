
> On Ubuntu

| Action | Keyboard Shortcut | Mouse / Alternative (CAD Style) |
| :--- | :--- | :--- |
| **Zoom In** | `Ctrl` +  `Alt` + `+` | ? |
| **Zoom Out** | `Ctrl` +  `-` | ? |
| **Box Zoom** | `Ctrl` + `B` | Drag selection box |
| **Fit All** | `V`, `F` | Click **Fit all** icon in toolbar |
| **Fit Selection** | `V`, `S` | Click **Fit selection** icon in toolbar |
| **Pan** | Arrow keys (`↑`, `↓`, `←`, `→`) | Hold **Middle Mouse Button** + drag |
| **Rotate View** | `Shift` + Arrow keys | Hold **Middle Mouse Button** + **Right Mouse Button** + drag |
| **Isometric View** | `0` | Numpad `0` |
| **Front View** | `1` | Numpad `1` |
| **Top View** | `2` | Numpad `2` |
| **Right View** | `3` | Numpad `3` |
| **Rear View** | `4` | Numpad `4` |
| **Bottom View** | `5` | Numpad `5` |
| **Left View** | `6` | Numpad `6` |

`Iso[0]->Front[1]->Top[2]->Right[3]->Rear[4]->Bottom[5]->Left[6]`
